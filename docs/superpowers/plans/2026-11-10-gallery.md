# Gallery + Cat of the Week Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/gallery` with likes, email moderation, the weekly Cat of the Week winner with its 4 rewards, and the bonus-credit change in Tango Me.

**Architecture:** Static Astro shells (`/gallery`, a home section, a Tango Me result button) fetch live data from n8n through new exact nginx locations. n8n owns all logic: moderation sub-workflow + endpoint, gallery list, like, opt-in, weekly winner, and a guarded change to the Tango Me workflow. State lives in new columns/tables in Postgres schema `ttw`.

**Tech Stack:** Astro 5 + TS strict, Vitest, nginx, n8n (Webhook/Code/Postgres/Gmail/Schedule/Execute Workflow nodes, Workflow SDK via MCP), Postgres 16.

**Spec:** `docs/superpowers/specs/2026-11-10-gallery-design.md` (project doc `claude/TTW_07_Gallery_Spec.md`). Read it before every task.

## Global Constraints
- Only the existing stack; no new services. Never print secrets.
- Ids: `^[A-Za-z0-9_-]{1,64}$`. Device id: `^[A-Za-z0-9_-]{16,64}$`.
- Likes: 1 per (device, IP) per image; **30** new likes per IP per day.
- Gallery list: `limit` 1–24 (default 24), `offset` 0–2000, `sort` `new|top` (default `new`); `featured` = latest `cat_of_week` with `week_start >= current_date - 13`.
- Cat of the Week: Monday **09:00 Europe/Berlin**; window last 7 days; tie → earliest `gallery_approved_at`; 0 likes → no winner; one win per image; re-run same week = no-op.
- Approve → `expires_at = 'infinity'`; remove → `expires_at = now()` + delete its likes; mod token single-use; **GET never mutates**.
- Owner email: `avcican@gmail.com` (Gmail node, existing credential).
- Free-use unique index `generations_free_use_uq` must stay; bonus generations keep `free_use_consumed = false`.
- All new UI strings in `src/i18n/en.json`; copy from spec §3 verbatim: "No guests yet. Luka is relieved.", "Easy, Budy. Come back tomorrow.", "The gallery is napping. Try again in a minute.", "Put your cat in the gallery", "Add to the gallery", "Sent. Luka will review your cat.", "Your cat is waiting for Luka's approval to join the gallery.", "Done. Luka has been informed.", "This link has already been used."
- Don't change approved home layout beyond inserting the new section after the scene polaroids.
- Before building any n8n workflow: `get_user_preferences`, `get_workflow_sdk_reference`, relevant `get_workflow_best_practices`. Export every changed workflow to `n8n/*.json`.

## Review Focus
1. **Gmail/Outlook link prefetch** hits the mod GET URL → nothing changes (Task 3 test "GET is read-only").
2. **Two tabs start Tango Me at once with one bonus credit** → exactly one generation gets the credit, the other is `used` (Task 4 test "parallel bonus claim").
3. **Image removed while its card is open / already liked in localStorage** → like returns `invalid`, heart rolls back, no crash (Task 6 test "like on removed image rolls back").
4. **Cat name with HTML/emoji (`<b>Mochi</b> 🐱`)** → escaped in owner email, mod page and gallery card (Task 3 test "escapes name"; Task 6 test "renders name as text").
5. **localStorage blocked (Safari private / embedded IG browser)** → gallery still loads and likes work for that page view (Task 6 test "no storage").
